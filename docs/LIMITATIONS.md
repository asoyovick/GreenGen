# Limitations

Global Change Explorer is a change-detection and visualisation tool, not a
scientific assessment report. It shows **observed past change** in
precomputed layers; it does not explain causes and it does not predict the
future.

## Scope

- **Observed change only, not a forecast.** No endpoint extrapolates beyond the
  observed record. If the UI ever showed “if the current rate continues”, that
  would be an explicit extrapolation with wide uncertainty, not a forecast;
  the current build does not do this.
- **Correlation, not causation.** Variables can change together for unrelated
  reasons or because of a shared driver. The tool does not attribute causes.
- **Single-cell summaries are not local truth.** The analysis grid is 0.5°.
  A report is for the nearest grid cell, not an exact address, field, or
  facility.

## Statistics and interpretation

- **Significance is FDR-corrected, not a raw p-value.** A cell is reported as a
  significant increase/decrease only when the Mann–Kendall trend (with
  Hamed–Rao autocorrelation correction) passes Benjamini–Hochberg FDR at
  α = 0.05 across tested cells.
- **“No statistically significant change detected” is not “no change”.** It
  means the evidence in this record was not strong enough to reject the null
  after correction. Real change can be present but noisy, short, or masked by
  variability.
- **Rates are estimates.** Theil–Sen slopes are robust to outliers, but they
  still depend on the period, missing months, regridding, and dataset quality.
  Rates should be read with the period, years used, and confidence flags.
- **Low confidence means short records.** Fewer than the configured “OK years”
  threshold (15 by default) is flagged as low confidence; the trend test still
  runs only when the minimum-years threshold is met.

## Data and coverage

- **Synthetic mode is not observations.** When `mode=synthetic`, every layer is
  generated by `scripts/make_synthetic_data.py` with planted trends for demo
  and testing. The UI and API mark this prominently as “SYNTHETIC DEMO DATA,
  not real observations.”
- **Real NASA processing has not been run in this environment.** The real
  pipeline is scripted and a credential-free CMR dry-run can verify catalog
  counts, but no authenticated Earthdata downloads, no real-file preparation,
  and no real trend layers were produced here. Any real-data claims require a
  team member to run the pipeline with Earthdata Login credentials and record
  the resulting manifests/DOIs.
- **NDVI (MOD13C2 v061) is HDF4.** The configured real dataset is HDF4 and is
  not opened directly by the NetCDF/xarray prep path. It must be converted
  (Harmony, rioxarray/GDAL, or pyhdf) before the real prep step; the pipeline
  will not silently fabricate it.
- **GRACE/GRACE-FO has a mission gap and coarse effective resolution.**
  `TELLUS_GRAC-GRFO_MASCON_GRID_RL06.3_V4` has a 2017–2018 gap between
  missions and mascon cells represent regional averages (hundreds of km). Gaps
  must be left missing, never interpolated, and the layer must not be presented
  as local detail.
- **Model-based datasets are not direct observations.** MERRA-2 temperature is
  a reanalysis. Trends can reflect real climate signals and/or changes in the
  assimilated observing system. The UI labels model-based variables.
- **Missing months are reported, never filled.** Prep records missing months in
  cube attributes/manifests; annual anomalies require enough valid months and
  years, otherwise values become gaps or low-confidence results.
- **Surface applicability is enforced coarsely.** Land-only variables (e.g.
  vegetation) are excluded where they do not apply; the inferred surface in a
  report is a convenience label based on available variables, not an
  authoritative land/water classification.

## Product and deployment

- **Precomputed layers only.** The API is a lookup service over generated
  `.zarr` layers and PNG overlays. It cannot answer questions that require
  recomputing trends, changing the period, or downloading new data at request
  time.
- **Offline assets are simplified.** The base map and place search are bundled
  offline assets (Natural Earth-derived geometry and a small gazetteer) for
  reliable demos; they are not a full geocoding or cartography service.
- **Frontend bundle size.** The production build currently ships a large map
  bundle (MapLibre/worker) and lazy-loads the chart library. Further code
  splitting would improve first load on slow connections.
- **No automated browser CI in this environment.** UI behaviour was verified
  with targeted builds/tests and the checkpoint records a prior manual
  Playwright smoke check with system Chrome; this is not the same as a
  repeatable headless CI run.
